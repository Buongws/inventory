# Inventory Learning

A NestJS API, Redis-backed rate-limit Gateway, and Next.js frontend in one repository.

## Start here

Read the active Product CRUD specification in [English](specs/001-product-crud/spec.md) or [Vietnamese](specs/001-product-crud/spec.vi.md). It records what is implemented, how to start the project, the 200 demo products, and the next recommended feature: inventory stock and stock movements.

## Structure

```text
apps/
  api/       # NestJS API :3001
  gateway/   # Rate-limit Gateway :3004
  web/       # Next.js :3002
docs/        # English documentation and Vietnamese translations
specs/       # Feature specifications generated by Spec Kit
scripts/     # Local development scripts
```

The root `node_modules` directory is for shared tooling (ESLint, Prettier, and TypeScript ESLint), not Spec Kit. Each app keeps its own dependencies and lockfile. Spec Kit uses the Python CLI, `.specify/` configuration, and `.agents/` skills at the repository root.

```text
Frontend :3002 → Gateway :3004 → API :3001 → PostgreSQL / Redis
```

## Install and run

Use Node.js 24. Each app has its own package-lock; the root only orchestrates commands and does not use npm workspaces.

```sh
npm ci
npm --prefix apps/api ci
npm --prefix apps/gateway ci
npm --prefix apps/web ci
```

Configure each app's `.env` from its example file. The API and Gateway share the JWT secret. Local development uses PostgreSQL `55433` and Redis `6379`; start both dependencies before the applications. The Google OAuth callback is `http://localhost:3004/api/v1/auth/google/callback`.

```sh
npm --prefix apps/api run migration:run
npm run dev
```

Frontend: http://localhost:3002/login. Swagger through the Gateway: http://localhost:3004/docs.

## Code checks

```sh
npm run check
npm run build
npm test
```

Each app supports `lint`, `format`, `format:check`, `typecheck`, and `build`. The root runs checks sequentially so an earlier app failure is visible. `npm test` runs the API Jest suite when tests are present. `npm run format` formats source files in all three apps.
