# Tài liệu tiếng Việt

Tài liệu tiếng Anh trong `docs/` là bản chuẩn của dự án. Thư mục này lưu bản tiếng Việt và ghi chú học tập theo từng chủ đề.

Nếu bản dịch chưa được cập nhật, hãy đối chiếu với tài liệu tiếng Anh cùng chủ đề.

- [`operations/PRODUCT_SEEDING.md`](operations/PRODUCT_SEEDING.md): tạo dữ liệu sản phẩm mẫu để thực hành local.

- [Inventory](inventory/INVENTORY_SPEC.md): tồn một kho, nhập/xuất, lịch sử và idempotency.

- [Flow Inventory](inventory/INVENTORY_FLOW_SPEC.md): giải thích UI, phân trang, transaction, retry và rời trang theo code hiện tại.
