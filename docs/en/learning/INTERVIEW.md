# Interview Practice

Practice each answer in 60–90 seconds using: definition, repository example, common failure, and verification.

Use [Database Practice](DATABASE_PRACTICE.md) for SQL, transactions, isolation, and inventory concurrency exercises.

1. Node.js Event Loop and CPU blocking.
2. `async/await` and rejected Promises.
3. `Promise.all` versus `allSettled`.
4. NestJS controllers, services, and modules.
5. Dependency injection.
6. Middleware, guards, interceptors, and pipes.
7. REST resource and error design.
8. Authentication versus authorization.
9. JWT signing, verification, expiry, and revocation.
10. Indexes and slow-query diagnosis.
11. Transactions, ACID, and isolation.
12. Race conditions when reserving inventory.
13. Duplicate webhook handling.
14. Redis cache-aside and invalidation.
15. Refresh rotation, family replay detection, and cleanup scheduling.
